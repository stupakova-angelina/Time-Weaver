# Time-Weaver

Умный планировщик учебного времени для подготовки к экзаменам. CLI‑утилита на Python, которая составляет расписание на основе приоритетов, дедлайнов и свободных слотов.

Проект создан как готовое решение для цифрового портфолио в конкурсе НТО: он показывает навыки работы с алгоритмами, обработкой данных, тестированием и проектированием интерфейса командной строки.

---

## Зачем это нужно

Когда подготовка к ЕГЭ идёт полным ходом, легко потерять баланс: либо делаешь только «срочное» и забываешь про «важное», либо забиваешь слоты впритык и выгораешь. TimeWeaver помогает:

- **Расставлять приоритеты** по разным стратегиям: жадно, сбалансированно или строго по дедлайнам.
- **Не ставить задачи впритык** — стратегия `balanced` добавляет буфер 15 минут.
- **Видеть загрузку** — статистика показывает, сколько часов реально запланировано и насколько загружены слоты.
- **Экспортировать результат** в JSON или CSV — удобно вставить в отчёт или показать в презентации.

Для тебя это ещё и персонализированный инструмент: в примерах лежат задачи под подготовку к ЕГЭ по информатике и математике, а слоты можно подставить под твои занятия с репетиторами.

---

## Возможности

- Три стратегии планирования: `greedy`, `balanced`, `deadline`.
- Загрузка задач и слотов из JSON.
- Вывод расписания в консоль.
- Экспорт в JSON и CSV.
- Сводная статистика: загрузка слотов, количество запланированных/незапланированных задач, распределение по важности.
- Конфигурационный файл и подробный режим вывода (`--verbose`).
- Тесты на ключевые алгоритмы.
