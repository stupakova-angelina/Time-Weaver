# Time-Weaver

Умный планировщик учебного времени для подготовки к экзаменам. CLI‑утилита на Python, которая составляет расписание на основе приоритетов, дедлайнов и свободных слотов.

## Возможности

- Три стратегии планирования: greedy, balanced, deadline.
- Загрузка задач и слотов из JSON.
- Вывод расписания в консоль.
- Тесты для проверки корректности работы.
